# Sketchly

Sketchly is an open-source infinite-canvas whiteboard for creating, editing, and sharing ideas visually.

## Features

- Infinite canvas with pan and zoom
- Freehand drawing with pressure support
- Shapes, arrows, lines, text, and sticky notes
- Image support with drag-and-drop
- Undo and redo
- Laser pointer for presentations
- Light and dark themes
- Grid backgrounds
- PNG export
- Responsive toolbar
- Keyboard shortcuts
- Real-time sync-ready data model
- React and React Native support

## Tech Stack

React · React Native · JavaScript · TypeScript · ESM · Vite
